# 文档命名与维护规范

文档按主题定位，按证据区分当前说明、历史记录和计划。所有模型说明随代码提交；模型权重、数据、缓存和运行日志保存在服务器或实验目录。

## 目录与命名

```text
docs/
  README.md                         总索引
  documentation-guide.md            本规范
  models/
    README.md                       模型主题索引
    rebuild-qwen35-2b.md             长期维护的重建说明
    model-registry.json             可读取的模型登记表
    records/
      2026-10-19/                    按核查日期保存的证据快照
        README.md                   证据含义与核查范围
        inventory.json              当时的服务器盘点
        models/                     下载和合并来源记录
        operations/                 当次重建/训练/验证脚本与记录
  templates/
    model-rebuild-record.md          可复用记录模板
```

- 新写的人类阅读文档使用小写英文及连字符：`<主题>-<用途>.md`，例如 `rebuild-qwen35-2b.md`、`load-memory-experts.md`。
- 长期维护的指南不在文件名堆叠日期、`final`、`new`、`latest`、`v2`；使用 Git 历史记录变化。
- 不可变运行记录以事件/核查日期 `YYYY-MM-DD/` 分目录。同日多次记录使用 `YYYY-MM-DD/<明确事件名>/`，不覆盖前一份证据。
- 机器读取文件使用明确名称，如 `model-registry.json`、`inventory.json`、`verification.json`。从服务器采集的原始证据保留原文件名及字节，允许其中已有下划线和大小写。
- 模型标识在正文登记为“模型家族 + 规模 + 领域/版本 + 阶段”，例如 `Qwen3.5-2B / code2 / SFT`。不要只写“2B”“新模型”“DPO3”。
- 本规范新增时不批量重命名旧文档，避免破坏已有链接。若以后迁移旧文件，需要同时更新引用和总索引。

## 每份说明应交代什么

指南的开头交代主题、结论、适用范围和最近核查日期；重建记录还应包含以下内容：

| 项目 | 必须明确的内容 |
| --- | --- |
| 动作性质 | 下载公开底座、重新合并 SFT、重新训练 DPO，还是迁移路径 |
| 身份 | 底座仓库/revision、SFT adapter、DPO adapter、当前路径及兼容路径 |
| 配置 | dtype、环境版本、训练参数、数据文件及哈希、随机种子 |
| 产物 | 输出目录、权重大小、哈希及来源记录位置 |
| 验证 | 形状、选定合并增量、重新加载、有限 logits、短生成、下游评测分别是否通过 |
| 局限 | 缺失的历史 revision、未重算的权重哈希、尚未重跑的验证或依赖 |
| 复现 | 对应确切版本脚本、命令工作目录、新输出位置，以及拒绝覆盖的约束 |

## 状态与证据用语

使用明确的动作描述，避免把所有状态写成“已验证”：

- **文件存在**：只证明目录或文件存在。
- **哈希匹配**：指出核对了哪个文件、与哪份记录比对、核对日期。
- **历史运行检查通过**：来源记录显示曾成功加载或生成；不等同于本次重新加载。
- **下游质量评测通过**：必须附数据、协议、指标和运行产物；短生成不能支持此表述。
- **历史身份未确认**：缺少当年 revision 时，即使重新合并可运行，也不能称为逐字节恢复原模型。
- **计划/示例**：不标成已部署配置；示例不能覆盖真实训练和验证记录。

引用优先级为：权重/源码哈希与原始运行记录 → 当前只读盘点 → 当时操作日志 → 说明文字。发生冲突时保留原始记录，补充解释和新的核查结果，不能静默修改历史证据。

## 新增与更新流程

1. 先核对现有说明和实际文件，确定应更新长期指南还是新增日期记录。
2. 将体积小且不含凭据的配置、来源清单和必要脚本保存本地；完整权重不进入 Git。
3. 在主题索引登记新增文档；重要入口同时登记到 `docs/README.md`。
4. 检查相对链接、JSON 可解析性、来源哈希与版本配对。保存原始脚本时用语法解析检查，不执行模型操作。
5. 与代码一样提交本地 Git。文档提交不代表已部署服务器，也不代表获得了向远端发布的授权。
